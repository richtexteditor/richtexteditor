# RichTextEditor - ASP.NET Core Razor Pages example

Complete runnable integration example: the editor wired into a ASP.NET Core Razor Pages app with upload handlers and AI endpoints.

**Run:** `dotnet run`

Also available as a template: `dotnet new richtexteditor-razor -n MyApp`.

- Docs: https://richtexteditor.com/docs/
- Live demos: https://richtexteditor.com/demos/

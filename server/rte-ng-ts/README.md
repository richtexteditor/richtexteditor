# RichTextEditor Angular demo

An Angular 20.3 LTS example using the current application builder and a reusable RichTextEditor component bridge.

## Run locally

```bash
npm install
npm start
```

## Production build

```bash
npm run build
```

The editor assets are served from `src/assets/richtexteditor`. See `src/app/rich-text-editor.component.ts` and `src/app/rich-text-editor-bridge.ts` for lifecycle and API integration.

# RichTextEditor - Blazor Server example

Complete runnable integration example: the editor wired into a Blazor Server app with upload handlers and AI endpoints.

**Run:** `dotnet run`

Also available as a template: `dotnet new richtexteditor-blazor -n MyApp`.

- Docs: https://richtexteditor.com/docs/
- Live demos: https://richtexteditor.com/demos/

Richtexteditor Configuration

Richtexteditor allows several ways to customize it to suit your needs.

For example:

You can customize the toolbar using editor.toolbar property.
  1. var editor1cfg = {}      
  2. editor1cfg.toolbar = "basic";      
  3. var editor1 = new RichTextEditor("#div_editor1", editor1cfg);   

As you can see, configurations are set by a simple JavaScript object passed to the editor instance.

You can customize the skin using editor.skin property.
  1. var editor2 = new RichTextEditor("#div_editor2", { skin: "rounded-corner", toolbar: "basic" });  

Global defaults — edit RTE_DefaultConfig at the top of rte.js

Every option you set on a single editor instance has a matching default on RTE_DefaultConfig. Those defaults live in plain, editable JavaScript at the top of the rte.js file you downloaded — only the licensed editor core below it is protected. Open rte.js in any text editor to change defaults globally — no rebuild required.

Example: change the default skin and toolbar for every editor on the page.
  1. RTE_DefaultConfig.skin = "rounded-corner";
  2. RTE_DefaultConfig.toolbar = "basic";
  3. RTE_DefaultConfig.showFloatParagraph = true;

Use per-instance config objects (shown above) when you want a single editor to differ from the site-wide defaults.

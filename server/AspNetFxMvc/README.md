# RichTextEditor - ASP.NET Framework MVC example

Complete runnable integration example: the editor wired into a ASP.NET Framework MVC app with upload handlers and AI endpoints.

**Run:** `Open the .sln in Visual Studio and press F5`

Targets .NET Framework - open with Visual Studio.

# Security Policy

## Reporting a vulnerability

Please report security issues **privately** — do not open a public issue.

- Email: support@richtexteditor.com (subject: "SECURITY")
- Or use the contact form: https://richtexteditor.com/support/

We aim to acknowledge reports within 2 business days. Please include a
proof-of-concept and the editor version (`RichTextEditor.version` or the
CHANGELOG entry) so we can reproduce quickly.

## Supported versions

Security fixes land in the current 2.x release line, distributed via
richtexteditor.com/download, npm (`@richscripts/richtexteditor`), and this
repository.

Editor Size

You can use width, height, min-height, max-height css properties to set the size of rich text editor.

Auto-growing editor (min-height: 300px)

Click the + button at the bottom-left of the editor to append a new paragraph — the editor grows vertically to fit. Use min-height instead of a fixed height so content can push the container taller as needed.

The min-height of this editor is set to 300px.

Rich Text Editor is the industry-leading online html editor. It enables content contributors easily create and publish HTML anywhere: on the desktop and on mobile.

Rich Text Editor toolbar is completely configurable and it is also effortless to implement. You just need a couple lines of code to add this editor to web applications.

Fixed-height editor (height: 300px)

With a fixed height, the editor stays the same size and content scrolls inside the editable area when it overflows.

This editor uses height: 300px. Clicking + still appends a new paragraph, but the editor does not grow — the content scrolls inside the fixed area.
